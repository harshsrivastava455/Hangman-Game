# Hangman Game

## Description

This is a simple text-based Hangman game built using Python. The player has to guess the hidden word one letter at a time. The game ends when the player guesses the word correctly or makes 6 incorrect guesses.

## Features

* 5 predefined words
* Random word selection
* Maximum 6 incorrect guesses
* Input validation
* Console-based gameplay
* Beginner-friendly Python project

## Requirements

* Python 3.x

## How to Run

### Option 1: Python Application (Used for this project)

I developed and tested this project using a Python application.

### Option 2: Command Prompt (Windows)

1. Open Command Prompt.
2. Navigate to the project folder.
3. Run:

```bash
python "Hangman game.py"
```

### Option 3: Visual Studio Code (VS Code)

1. Open the project folder in VS Code.
2. Open `Hangman game.py`.
3. Click **Run** or press **F5**.

### Option 4: PyCharm

1. Open the project in PyCharm.
2. Open `Hangman game.py`.
3. Click the **Run** button.

### Option 5: IDLE

1. Open `Hangman game.py` in IDLE.
2. Click **Run → Run Module (F5)**.

### Option 6: Online Python Compiler

You can also run the code on online Python editors such as Programiz, Replit, or OnlineGDB by copying and pasting the code.
